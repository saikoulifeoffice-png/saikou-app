# カードセンタリング測定

トレーディングカード（63×88mm、ポケモンカード等）の写真・スキャン画像から、
左右・上下のセンタリング比率を測り、PSA基準での目安グレードを表示するWebサイトです。

- HTML / CSS / JavaScript のみ（ビルド不要）
- 画像処理は OpenCV.js（`lib/opencv.js` に同梱。外部CDNを使わない）
- 画像はサーバーに送らず、ブラウザ内だけで処理

> 本サイトは非公式のファンメイドツールです。株式会社ポケモン・任天堂・各鑑定会社とは関係ありません。
> 表示されるグレードは目安であり、公式判定ではありません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面 |
| `css/style.css` | 見た目（スマホ優先・ダークモード対応） |
| `js/app.js` | 画面操作・結果表示 |
| `js/measure.js` | 画像処理（カード検出・透視補正・枠の測定） |
| `js/grading.js` | PSA基準表とグレード判定 |
| `lib/opencv.js` | OpenCV.js 4.10（@techstark/opencv-js） |
| `tests/accuracy.mjs` | 人工カード画像を使った精度テスト |

## 測定のしくみ

1. カードの外形（四角形）を検出（エッジ検出＋明るさの2値化の両方で探す）
2. 透視変換で 63×88mm の比率に補正（1mm=25px → 1575×2200px）
3. 補正画像の外枠を各辺31本の走査線で測り直し、直線を当てはめて四隅を精密化 → 再補正
4. 各辺41本の走査線で「外枠（カードの端）」と「内枠（ボーダー色が変わる所）」を検出
   - 明るさ・色の変化が最大になる位置を放物線補間してサブピクセル精度で求める
5. 外れ値（中央値から3σ以上）を除き、中央値をボーダー幅とする
6. ばらつきから誤差を計算（下限±0.2%）。有効な走査線が少ない・誤差が±1%超などのときは信頼度「低」として再撮影を促す

## 精度テスト

```
node tests/accuracy.mjs
```

黄色枠・銀枠・裏面（青枠）の人工カードを、回転±15°・斜め撮影・ぼかし・ノイズ・JPEG圧縮をかけて18枚作り、
正解との差を測ります。現時点の結果：**平均誤差 0.05%、最大誤差 0.18%**（目標 ±1%以内）。
※実写真では照明・反射・カードの反りなどで誤差が増えます。

### 既存アプリの仕組み
多くは「写真を撮る → 自動で枠を検出 → ガイド線を手動で微調整（拡大表示あり）→ 左右・上下の比率を計算 → 各社基準と比較」という流れ。

### ポケモンカードの枠
- 英語版はスカーレット・バイオレット以降、黄色枠 → 銀枠に変更（日本版は2010年のBWから銀枠）
- 日本版は英語版より枠が細めとされ、同じズレ量でも比率が大きく出やすい
- フルアートも外周に細い枠があり、その内側の絵柄との境目を内枠として測る
- 裏面は青い枠と、内側の濃い青の渦模様の境目で測る
