# 貴金属買取（簡易版）

従業員が顧客情報と買取商品を入力すると、参考相場から地金総額と見込み利益を自動計算し、取引履歴を保存します。
設定の「画面モード」が **簡易版**（既定）のとき、メニューはこの機能のみ表示されます（全機能に切替可）。

## 画面

| 画面 | パス | 権限 |
|---|---|---|
| 買取登録 | `/gold/new` | 全員（従業員は自分が担当者、代表・管理者は担当者を選択可） |
| 買取履歴（名前・日付・担当者で検索、詳細） | `/gold`, `/gold/[id]` | 従業員は自分の担当分のみ、代表・管理者は全件 |
| 相場管理 | `/gold/prices` | 閲覧は全員、登録・修正は代表・管理者 |
| 買取集計（日別・月別、従業員別、CSV） | `/gold/reports` | 従業員は自分のみ、従業員別は代表・管理者 |

## 計算仕様

| 項目 | 計算 |
|---|---|
| 商品別地金金額 | 重量(g) × 参考相場単価(円/g)、1円未満を**四捨五入** |
| 地金総額 | 商品別地金金額の合計（丸め後の合計） |
| 見込み利益 | 地金総額 − お客様への支払額（マイナスもそのまま表示） |
| 利益率 | 見込み利益 ÷ 地金総額 × 100（小数1桁、地金総額0円のときは「—」） |

- 重量・単価は小数2桁まで。計算は整数（1/100単位）で行い浮動小数点誤差なし
- **金額はサーバー（DB）で再計算**して保存。画面の値は確認用（両者の一致はテストで検証）

## 参考相場

- 日付 × 品位ごとに保存し、取得元・取得元URL・取得日時・登録者・登録方法（手動/自動）を記録
- 買取登録時は買取日の相場を自動適用。買取日の相場がなければ**直近の過去日の相場**を適用し警告。どちらもなければ警告し、単価の手入力を求める
- 適用した単価・相場日・適用区分（当日相場／直近の相場／手入力）を**買取明細に保存**。相場マスタを後から修正しても過去の記録は変わらない（DB で更新禁止）
- 参考相場は見込み利益の計算用であり、**実際の売却価格ではない**（画面・確認ダイアログに明記）

### ゴールドミセス（https://goldmrs.jp/）の相場の登録

- goldmrs.jp はクラウド環境からのアクセスを **403（アクセス拒否）** で返すため、自動取得は行っていません（制限の回避はしない）。
  公式に認められた取得方法（API・データ提供）も確認できていません
- 代わりに相場管理画面で次の補助を用意しています
  - 「ゴールドミセスの相場を開く」ボタン（取得元URLは既定で https://goldmrs.jp/ を記録）
  - **相場表の貼り付け読み取り**: サイトの相場表をコピー＆貼り付けすると、品位ごとの単価を自動入力（`lib/gold/paste.ts`。K18/18金、Pt900/プラチナ900、全角数字などの表記ゆれに対応）
  - 「前回の相場をコピー」: 変わった品位だけ修正
  - **変動チェック**: 前回の相場から20%以上変わった品位は警告（10gあたり価格の取り違え等の防止）
- 読み取り結果は必ず画面で確認してから保存します（自動保存はしない）

## データ・権限

- テーブル: `pm_grades`（品位）, `pm_market_prices`（相場）, `pm_purchases`（買取）, `pm_purchase_items`（商品）
- すべて RLS 有効。書き込みは検証付き RPC（`pm_register_purchase` 等）のみ
- 登録後の買取内容は変更不可。誤りは代表・管理者が取消（理由必須・履歴保存）して再登録
- 顧客情報（名前・電話・住所）は担当従業員と代表・管理者のみ閲覧可
