# ネット集客の仕組みづくり：現状の問題点と作業計画（2026-11-19）

## A. 公開中サイトの問題点
| # | 問題 | 影響 |
|---|---|---|
| 1 | 住所表記が揃っていない：4つのLP・地域×事業ページに「大**畑**与野ビル」の誤字。「事務所202」と「202」が混在。構造化データの郵便番号が空欄 | NAP（会社名・住所・電話）の不一致は地図検索の評価を下げる |
| 2 | メタディスクリプション・OGPが全ページ未出力（SEOプラグインなし） | 検索結果の説明文をGoogleが自動で選ぶ／SNSで共有したときに画像が出ない |
| 3 | GA4・GTMが未設置。問い合わせ計測のスクリプト（電話・LINE・フォーム送信／ページ・地域・事業別）は準備済みで、送り先がないだけ | 問い合わせ月3件が「どこから来たか」分からない |
| 4 | タイトルが「…なら株式会社saikou - 株式会社saikou」と重複。屋号（暮らし整理SAIKOU等）が入っていない | 指定の「地域名＋サービス名｜屋号」になっていない |
| 5 | 文言の食い違い：現在の各LPは「追加費用がかかる場合あり」。新しい指示は「見積もり後の追加料金なし」 | 景品表示法上、条件を揃えて書く必要がある |
| 6 | LPに問い合わせフォームが埋め込まれていない（/contact/ へ移動する作り）。LPにもサイト全体のメニューが出ている | 「LP内で完結」の方針と合わない |
| 7 | ブログ記事0本（カテゴリー「コラム」配下に4事業の子カテゴリーは作成済み） | 検索の入口がない |
| 8 | 地域ページ約365件が地名を差し替えただけの内容（本文の一致率100%） | 重複ページとして評価が下がるおそれ |
| 9 | お客様の声・実績の件数が0、実際の写真が少ない | 信用材料が足りない |
| 10 | テーマの背景色が黄色のまま（フッター上に黄色い帯） | デザイン方針（白基調）と合わない |

## B. 作成済みの下書きで直す点（新しい指示との差分）
- トップ（ID 1817）：流れを「トップ画像 → あいさつ → 地域密着・実績 → 4事業 → 声・実績 → FAQ → お問い合わせ」に組み直す。メインコピーを「私たちは、お客様の立場に立って寄り添います。なんでも相談してください。」に差し替え、配色を白基調＋グリーン・ブルーに寄せる
- 4事業LP（ID 1823〜1826）：LP同士のリンクを削除、運営会社とフォームを追加、料金の後に問い合わせボタンを追加、スマホ下部の固定バーを「電話・LINE」の2つに、屋号を表示、確定した事実（女性スタッフ・最短30分＋注釈・立ち会いなし・供養など）を反映

## D. 目標（月30件）について
サイトの改善だけで月3件を10倍にするのは難しく、次の3つを並行して進めるのが現実的。
1. Googleビジネスプロフィール（地図検索）：住所表記の統一、写真の追加、実際の口コミを集める
2. ブログ：毎月の積み上げ（40本は最初の土台）
3. 計測：どのページから問い合わせが来るかを見て、成果の出る記事・LPに力を集中する
